01 / Orientation

Start Here

  1. Check the technology inventory and environment before choosing an output.
  2. Find the output in the asset dictionary. Follow upstream arrows in the data-flow view.
  3. Use the pipeline catalogue and evidence links to locate responsible definitions.
  4. Read control-flow conditions separately. A dependency does not establish data movement.
  5. Review coverage findings before making an operational decision.

Business purpose, ownership, SLAs, actual run success and recovery procedures require reviewed documentation or time-bound runtime evidence. This handbook does not infer them from names.
